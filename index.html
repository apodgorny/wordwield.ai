01 / RuntimePublic source

Almasi

Your filesystem becomes your runtime.

A Python runtime that resolves library components directly from filesystem structure. Compose and extend libraries through ordinary Python classes, inheritance, and plugins.

Explore code ↗Watch overview ↗
02 / Object worldPublic source

Almasi.o

Persistent Python objects, shared.

A persistent object model unifying identity, relationships, validation, schema, and state. Applications and agents work with the same entities, with fewer representations to synchronize.
